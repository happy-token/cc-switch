# HappySwitch 使用教程

完整图文教程对应官网 `/zh/docs/happyswitch`；上线前可在本地预览。配图为操作示意，不含真实账户数据。

## 1. 安装

从 [下载页](https://happy-token.cn/zh/downloads) 下载 HappySwitch。Mac 打开 DMG，拖入“应用程序”；Windows 下载 EXE，按向导安装。Codex、Claude Code 等编程助手需要另行安装。

## 2. 登录

点 HappySwitch 左下角“登录 HappyToken”。在默认浏览器登录，核对浏览器和应用的验证码相同，再确认授权。已登录的浏览器会直接进入授权页。

## 3. 启用配置

回到 HappySwitch，在左侧选你要用的助手，找到导入的 HappyToken 配置，点击“启用”。导入不会自动切换当前配置。Codex 可以先试 gpt-pro，Claude Code 可以先试 default；实际可用配置以账户权限和助手兼容性为准。

GPT Web 目前留给网页助手，Image 用于图片创作，不自动导入编程助手。

## 4. 试用

打开或重启助手，新建会话，试着让它解释一段代码。需要看扣费时，点 HappySwitch 左下角账户名，再打开“控制台”。

## 日常操作

左下角账户面板可以查看余额和累计消费、充值、打开控制台、更新配置和退出登录。

余额是最近同步的数值；充值或分组变化后点“更新配置”，在浏览器再次确认授权。这不是软件升级按钮。

退出登录不会删除已有配置、撤销 API Key 或退出浏览器账户。共用电脑时还需另行处理本机配置与浏览器登录。

## 遇到问题

- 浏览器没打开：在等待窗口点“重新打开浏览器”。
- 授权过期：取消后重新登录。
- 没有导入配置：先到控制台确认有可用分组，再更新配置。
- 助手仍走旧配置：确认选对助手、配置已启用，重启或新建会话再试。
- 仍然报错：联系支持并提供助手、分组与报错；隐藏 API Key。
